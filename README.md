# Sales Performance Dashboard

## Project Overview
This project analyzes sample sales data using Python to understand sales performance, profitability, and business trends.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Google Colab

## Project Objectives
- Calculate total sales and total profit
- Analyze region-wise sales performance
- Compare product-wise sales
- Visualize business performance using charts

## Key Performance Indicators (KPIs)
- Total Sales
- Total Profit
- Region-wise Sales
- Product-wise Sales

## Project Workflow
1. Create and load the sample sales dataset
2. Analyze data using Pandas
3. Calculate business KPIs
4. Group sales by region and product
5. Visualize results using Matplotlib

## How to Run
1. Open the Jupyter notebook in Google Colab
2. Run the code cells in order
3. Review the calculated KPIs and charts
